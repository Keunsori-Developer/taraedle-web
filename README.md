## 한글로 풀어보는 워들, 타래들

### 프로젝트 설명  

기존에 존재하는 게임인 워들 게임을 참고하여 한글로 풀 수 있는 워들 게임을 만들었습니다.

### 프로젝트 내 역할

해당 프로젝트는 웹과 모바일로 분리된 프로젝트로, 저는 그 중에서도 웹 프론트엔드를 맡아 해당 프로젝트의 웹 버전을 개발했습니다.

### 기술 스택

React.js, Typecript, Tailwind, Chart.js
